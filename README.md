# speakdaily-templates

Blank lesson templates for SpeakDaily's Friday automation, plus the image drop folders.
Finished lessons are NOT stored here - they're delivered in Claude and kept in the private repo.

- Change a template: replace the `TEMPLATE_` file in `templates/<language>/` with your newer approved deck (keep the `TEMPLATE_` prefix).
- Images for a week: see `images/README.md`.
