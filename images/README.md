# Image drop folders

Drop photos here by **Thursday night** (any time before Friday 3am Lisbon). That Friday's run uses them and lists them in its log, so they're never reused. You can delete them after that Friday if you like.

- `english/` - for an Advanced English image class (3-4 images = one class). Each batch can go in its own subfolder if you want more than one image class that week.
- `spanish/` and `portuguese/` - for a "describe what you see" picture section inside one of that week's decks (1-3 images per deck).

Optional: add a `note.txt` next to the images with what you want, e.g. "deeper meaning" or "describe in detail" or "use with the verb comer".

No images? Nothing breaks - the runs just build that week's lessons without image sections.

How to upload: open the folder on github.com, click **Add file → Upload files**, drag the photos in, click **Commit changes**.

Note: this repo is public, so anyone with the link can see what's in it. Only put photos here that you're happy to be public.
